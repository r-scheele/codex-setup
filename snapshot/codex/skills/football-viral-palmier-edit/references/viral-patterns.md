# Viral Football Edit Patterns

Use this reference to convert current YouTube research into a Palmier edit brief.

## Seed Findings

The initial seed set had these public signals:

| Format | Example signal | Why it works |
|---|---:|---|
| Best edits/fails/goals/skills compilation | 6.1M views on a 2025 RMHD TikTok/Reels compilation | High-volume clips, broad promise, SEO title repetition, easy continuous watching |
| Tutorial/listicle | 9.1M views on "25 ways to shoot..." | Clear number, training value, search intent, evergreen usefulness |
| "SuperHuman" spectacle | 8.3M views | Curiosity gap, impossible moments, emotional awe |

| Funny goals/moments | 3.5M views | Humor promise, low barrier, shareability |

Fresh research should update these patterns rather than copying old titles.

## Viral Levers To Look For

- Title promise: "Best", "1 in a Million/Trillion", "SuperHuman", "Impossible", "Funny", "Skills", "Fails", "Goals".
- Broad clip variety: goals, dribbles, nutmegs, saves, keeper mistakes, crowd reactions, celebrations, comedy.
- Retention loop: no long intro; visual payoff in first 3 seconds; new moment every 2-6 seconds.
- Rewatch triggers: slow-motion skill, surprising failure, impossible angle, celebrity/player recognition.
- Packaging: bright action thumbnail, ball/player face visible, 2-4 words max, high contrast.
- SEO: football/soccer, goals, skills, fails, funny, compilation, TikTok, reels, year, player names when relevant.
- Complete-goal satisfaction: when the edit is built around goals, viewers need to see the move that creates the chance, the finish, and the goal scorer's celebration. Do not start every clip on the final touch or cut away on the ball crossing the line.
- Human-feeling audio: default to original commentary and crowd only. Let the broadcast call, crowd roar, player names, and stadium emotion carry the pace. Clean the audio with loudness normalization/compression and use short gain rides around key moments; do not add songs unless explicitly requested.
- Numerical mix targets: distinguish gain requests from relative-gap requests. If a user says "12 dB instead of 17-25 dB," target about a 12 dB commentary-over-music stem gap, not +12 dB extra commentary gain. When one global duck makes some song sections too quiet, use per-goal/per-window values and keep broad goal windows close to full music.
- Moment-aware pacing: place transitions, push-ins, slowdowns, replays, and celebration peaks around the real football action and commentary/crowd surges. If music is explicitly requested, then also consider musical hits.
- Anti-template polish: avoid repeated full-screen score cards, generic motivational captions, random flashes, and effects that are not tied to the ball, the player, the celebration, or the beat.

## Footballia Source Selection

Default to Footballia matches from 2020-present. Prefer sources that can naturally support a viral edit for Europe, the UK, and the US:

- High-event matches: 3+ goals, visible goal timestamps, penalties, red cards, keeper chaos, comeback energy.
- High-interest context: Champions League, Euro, World Cup, Premier League, finals, semi-finals, derbies, title deciders.
- Recognizable teams/players: Real Madrid, Barcelona, Manchester City, Manchester United, PSG, Inter, Dortmund, Chelsea, Liverpool, Arsenal, Spain, England, Argentina, Portugal, Messi, Ronaldo, Mbappe, Haaland, Vinicius, Bellingham, Lamine Yamal.
- Packaging-friendly story: comeback, last-minute goal, giant upset, rivalry, star duel, funny collapse, or impossible skill sequence.
- Avoid low-event 0-0 matches unless the user asks for tactical analysis or there is a very specific viral hook.

## Europe/US Monetization Target

- Use English titles, descriptions, captions, and thumbnail text by default.
- Bias source selection toward Champions League, Premier League, Euro, World Cup, elite European clubs, English-speaking fanbases, and US-recognizable stars.
- Package with searchable US terms (`soccer`) and European terms (`football`, `UCL`, `Premier League`) together.
- Keep the video advertiser-friendly: no misleading title/thumbnail, no excessive profanity, no harassment framing, no graphic injury replay loops.
- Make reused footage meaningfully transformed: add a storyline, commentary/narrative captions, substantive sequencing, key-moment zooms/speed ramps/replays/reactions, visual rhythm, effects, and context. Avoid plain clip dumps. This supports originality but does not guarantee monetization.
- If a YouTube upload is blocked by copyright checks, move from "highlight edit" to "analysis/story edit": remove broadcast audio, add original narration or text commentary, use annotated freeze frames, explain decisions and stakes, and use short source moments only as evidence. Do not rely on technical evasion tricks.

## Edit Templates

### Compilation Reel

Use when the source has many distinct events.

- 0-3s: strongest moment first, no context.
- 3-12s: quick identity setup with 3-5 clips.
- 12-45s: alternating pattern: goal/skill/fail/reaction.
- 45-60s: densest run of premium moments.
- 60-75s: one final funny or shocking payoff, then quick subscribe/title card.
- For complete-goal compilations, let goals run longer than the 2-6 second novelty loop when needed. Trim dead time, not the playmaking, finish, or scorer celebration.
- Use audio contrast: let match commentary and crowd drive buildups. Raise the best calls and roars slightly, let quieter buildup breathe, and use visual rhythm instead of a song bed to create energy. If music is explicitly requested, keep broad goal windows musical and use short tighter ducks for iconic calls.

### Superhuman/Awe Edit

Use when the source has elite skills, saves, long shots, acrobatics, or legendary players.

- 0-5s: impossible-looking outcome.
- 5-20s: build with closeups and crowd tension.
- 20-50s: escalating feats, speed ramps and freeze emphasis.
- 50-70s: best moment plus replay angle.
- Layer commentary only when it adds awe or context. Otherwise let the music and crowd breathe.

### Funny Football Edit

Use when the source has mistakes, slips, missed chances, mascots, refs, keeper chaos, or reactions.

- 0-2s: funniest visual first.
- 2-25s: rapid jokes, each clip 1-4s.
- 25-50s: escalate absurdity; add punchy captions sparingly.
- 50-65s: callback to first joke or biggest fail.

### Tutorial/Listicle

Use when making instructional content from training or match examples.

- Number every item visually.
- Make each segment 10-25s.
- Show the result first, then the setup.
- Use simple labels, not paragraphs.

## Palmier Prompt Recipe

Build each prompt from:

1. Current research summary: 5-10 videos, titles, view counts, common promises.
2. Source footage inventory: goals, skills, fails, reactions, player names, standout timestamps.
3. Pattern board: title formula, thumbnail promise, first-5-second hook, pacing, and what to adapt without copying.
4. Audio plan: commentary-only by default, original narration/caption-led analysis when copyright-blocked, any requested music source, ducking points only if music is explicitly requested, sync/retime strategy, and audio confirmation method.
5. Selected template above.
6. Upload pack: title options, description, tags, thumbnail concept.

Keep the final edit prompt action-oriented: tell Palmier what to inspect, what clips to select, how long each section should be, and what files to write.
